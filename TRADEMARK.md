## Why This Policy Exists

Open-source code needs trademark protection, or the project name
becomes unusable. If anyone could ship a fork called "Laurevine
Rose", users would not know which version was the official one. This
policy protects users by ensuring "Laurevine Rose" always means the
software distributed by Biowess.
